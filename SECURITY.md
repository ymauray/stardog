# Security policy

## Supported versions

| Version | Supported |
| --- | --- |
| `main` / latest release (also what https://ymauray.github.io/stardog/ serves) | :white_check_mark: |
| Older releases | :x: |

## Reporting a vulnerability

**Please do not open a public issue.**

Use GitHub's private vulnerability reporting: go to the [Security tab](https://github.com/ymauray/stardog/security) and click **Report a vulnerability**.

Describe the problem, how to reproduce it and its potential impact. The report will be looked at as soon as possible, and a fix will be published before any public disclosure.
